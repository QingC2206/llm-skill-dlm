# SOP 路由

> **用途**: 按实际场景查找相关操作方法。用户请求、任务需要或 manifest 可提供入口；无需为了读取 SOP 先建立任务或加载整个索引。

## 使用规则

- SOP 是场景规程, 不是 L0 红线。只有所有场景都不可违反的约束才应升格为 L0。
- SOP 可以包含 Markdown 流程、检查清单和可选 Python 校验命令。
- SOP README 的正文结构可以按场景自定义; validator 只强制 front-matter 和路由入口, 不强制固定二级标题。
- Python 只做确定性检查; 审美、交互合理性、收益 / 风险和例外是否成立仍由 LLM 判断。
- 新建或更新后校验受影响的 SOP 与路由。
